# EAGER_scRNA-seq

Tutorial on data dimensionality reduction using single-cell RNA-seq data.

## Open the Nautilus Server

https://tsc.fullerton.edu/supercomputing/nautilus.html

## Download the tutorial

```bash
curl -LO https://raw.githubusercontent.com/CSUF-EAGER/EAGER_scRNA-seq/main/scripts/Alex_Tutorial.ipynb
```

## Download the data

```bash
pip install gdown
gdown --folder "https://drive.google.com/drive/folders/18IYXtfmcj5pR3TCVYrOBUStuvQ4kkpC5" -O data
```

~970 MB, lands in `data/`.

Setup instructions are in the notebook.
